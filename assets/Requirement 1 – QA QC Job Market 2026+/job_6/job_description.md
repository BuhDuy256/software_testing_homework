## Qualifications

### General Requirements
- Intermediate or higher English proficiency.
- 2.5+ years of hands-on experience in automation testing.
- Able to self-learn and quickly adapt to new technologies.
- Familiar with Agile development methodologies.
- Able to perform tasks under high pressure.

### Technical Requirements
- Deep domain knowledge of API, UI automation, web and mobile applications.
- Strong domain knowledge of the software development process, especially the software testing process.
- Solid testing experiences: requirement analysis, test strategy, test approach, test plan, test techniques (black box, risk-based, exploratory, non-UI testing, etc.).
- Good coding skill in **Python, Java, JavaScript**.
- Experience in CI/CD (Apache Airflow, Git, Jenkins, etc.) is a plus.
- Hands-on experience with test tools like TestNG, Mocha, Jasmine, Nightwatch, etc.
- Experience with tools: Postman, Git, IntelliJ IDEA, soapUI, cURL, fetch, etc.

### Nice to Have
- Experience using AI chat tools (ChatGPT, Claude, Gemini, etc.) for research, debugging, and learning.
- Familiarity with at least one AI coding assistant (GitHub Copilot, Cursor, Claude Code, or similar).
- Ability to write clear, contextual prompts to generate code snippets, unit tests, or documentation.
- Awareness of AI output limitations and responsible AI use (data privacy, handling of sensitive client data).
